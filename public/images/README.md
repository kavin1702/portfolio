Put project screenshots and your profile photo in this folder.

Tips so the site stays fast:
- Use .jpg or .webp, about 1280px wide for project covers, 800px for your profile photo.
- Keep each file under ~300 KB (squoosh.app can shrink them for free).
- Use simple lowercase names without spaces, e.g. fire-safety.jpg
- Videos go on YouTube (Unlisted is fine), not in this folder.
